Двумя основными компонентами pandas являются Series и DataFrame. Series — это, по сути, столбец, а DataFrame — это двумерная таблица, состоящая из набора Series.
В переменной data, как вы могли догадаться, находится DataFrame. Чтобы вывести первые строки на экран, воспользуемся методом head() (в скобках можно указать количество выводимых строк, по умолчанию - 5). Можно вывести информацию о данных методом info():
- data = pd.read_csv('titanic.csv')
- data.head()
- data.info()
Для данных, используемых при анализе, важно учитывать вид переменной. Она бывает категориальной или количественной.
Категориальная переменная описывает свойство, относящиеся к какой-либо категории. 
Количественная переменная описывает количество чего-либо. С количественными переменными можно выполнять различные вычисления - например, находить среднее.


Как вы помните, в переменной data хранятся все данные в виде DataFrame. Так как мы будем обрабатывать значения в каждом столбце отдельно, важно уметь обращаться к этим столбцам. Есть два способа:
-        Через квадратные скобки: data[‘Age’] ;
-        Через точку: data.Age .


Гистограмма строится методом hist() и показывает, как часто встречается в данных определенное значение. 


Можно обойтись без графика и подсчитать количество каждого значения методом value_counts(): data['Survived'].value_counts()


Отбор признаков – это важная тема, потому что далеко не всегда признаки, описанные в датасете влияют на целевую переменную. Например, имя клиента банка не влияет на то, просрочит ли он кредит. Чтобы удалить признаки, есть отдельный метод drop(). В скобках указываем название/я столбцов для удаления, а также ось, по которой оно будет производится (при axis=0 будут удалены строки, а не столбцы). data = data.drop(['PassengerId', 'Name'], axis=1)


Существует простой метод для расчета статистик всех столбцов с количественными значениями – describe(): data.describe()


Чтобы отдельно рассчитать значениями для столбца, можно воспользоваться соответствующими методами: mean(), median(), max(), min(). 


Удаление и заполнение пропусков. Метод .sum(), чтобы увидеть сумму пропусков по каждому столбцу: data.isnull().sum()


Заполним пропуски медианным значением, так как оно меньше подвержено выбросам (в отличие от среднего). Для этого есть отдельный метод fillna(), в аргументе которого указывается значение, на которое заменяют пропуск: data['Age'] = data['Age'].fillna(data['Age'] .median())

Заполнение пропусков и работа с ними — это отдельная сложная тема и не во всех случаях заполнение медианой подойдет. Чаще всего нужно действовать логически. Допустим, в ваших данных есть столбец “Дети” (“children”) и значения следующие: 0, 3, 2, 1, 4, NaN. Если встретится пропуск (пустая строка или NaN), можно смело предположить, что у человека/пассажира/пациента нет детей и отсутствующие значения заменить на 0.

Во временных рядах (такие же датасеты, только значения отсортированы по времени и в них важен порядок, например, параметры погоды за N месяцев) пропущенные данные заменяют предыдущими или последующими в зависимости от ситуации. Если в датасете с погодой есть данные о влажности за 14, 15 и 17 дни месяца, то вместо пропуска в 16 дне подставят значения 15 или 17 дня (а может возьмут среднее арифметическое).

Иногда создают отдельную переменную “unknown”, к которой относят все отсутствующие значения.

А в больших проектах специалисты по машинному обучению могут даже вручную вставлять отсутствующие значения. Например, если в датасете с квартирами есть пропуски, специалист может найти в интернете (если сможет) определенное объявление и заполнить недостающие значения, допустим, о количестве комнат.

Объемный метод where(). Первым обязательным аргументом должно быть условие, а далее (не обязательно) идет действие. 

Важно уметь не только загружать готовый DataFrame, но и создавать его. Делается это с помощью одноименного метода pd.DataFrame(). Создание может осуществляться разными способами, но легче всего это сделать через обычный словарь. Можно задать индексы при создании DataFrame с помощью аргумента “index”:
- import pandas as pd
- df_fruits = pd.DataFrame({
-     'apples': [3, 2, 0, 1],
-     'oranges': [0, 3, 7, 2]
- })
- df_fruits = pd.DataFrame(data, index=['June', 'Robert', 'Lily', 'David'])
- df_fruits
